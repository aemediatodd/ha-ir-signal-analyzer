# IRDB attribution

This integration downloads and accesses data from
[irdb](https://github.com/probonopd/irdb).

Contains/accesses irdb by Simon Peter and contributors, used under permission.
For licensing details and for information on how to contribute to the database,
see https://github.com/probonopd/irdb

IRDB data is not bundled in this repository. Home Assistant downloads a snapshot
at runtime and stores it locally for offline matching.
